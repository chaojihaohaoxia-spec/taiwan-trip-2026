# 规则包（网页和小程序共用）

源头在 `app/src/rules/`（普通 ESM、纯函数、零依赖、不用 Intl），接口说明见 [`app/src/rules/README.md`](../app/src/rules/README.md)。

- **管什么**：「这一项怎么去 → 给哪些按钮」（`how.js`）、目的地档案（`dest-data.js` 地区 + 城市规则、`dest-cities.js` 城市搜索、`dest.js` 读档案）、币种写法（`currency.js`）、坐标工具（`geo.js`）。
- **两端怎么用**：网页直接 `import`；小程序那份由小程序项目的 `tools/sync-core.sh` 用 esbuild 生成（`--bundle --format=cjs --target=es2015 --minify --charset=utf8`），放主包，`dest-cities.js` 放分包 `pkg-trip`；云函数 trip 不拷规则包。
- **金标准**：`app/src/rules/cases/*.json`，网页 `test/unit/rules.cases.test.js` 跑三遍（ESM、打成小程序那份、删掉 Intl），小程序 `tools/test-trip-rules.js` 用同一个 `cases/runner.js` 再跑一遍，结果必须一样。
- **行程上存什么**：`trips.extra.dest = { v, region, cities, move?, ride?, walk_km? }`、`segments.extra.dest = { region, city?, move? }`，只存选择和改动；紧急电话、插座、小费从内置表现算（改表以后老行程跟着对）。写法检查 `destOk` / `segDestOk` 和服务器 `private.dest_ok` 一致。
- **档案的底线**：每个地区的紧急电话、插座、小费要人工核过来源（`dest-sources.js`），核过的行写 `checked` 日期；没核过的地区界面上不显示这三样，只给币种和叫车。
- **公开仓库**：用例只用演示数据（椰影岛、雾港、南湾）；真实行程的影响报告在私有目录 `行程数据/tools/how-report.mjs`，不进仓库。
