# pages/bookings/ —— 预订（`#/t/:tripId/bookings`，SPEC §5.6）

「更多」菜单里的「预订」。外壳画大标题「预订」、左上返回、副标题（行程名）、右上搜索（`section` 类页面，见 shell/README）；
这一页从大标题下面开始。点卡片打开全站共用的**预订详情弹层**（`sheets/booking/`，同一个预订在两处长得一样的部件也在那边）。

| 文件 | 内容 |
|---|---|
| `BookingsPage.jsx` | 页面：读数据、分组 / 筛选、加载中 / 出错 / 找不到行程 / 没有预订 / 筛选后为空、进来自动滚、已取消的收在最下面 |
| `Summary.jsx` | 顶部：`Summary`（一行字）、`Recap`（已结束的回顾）、`Today`（进行中「今天用得上的」）、`MoneyList`（一串金额） |
| `BookingCard.jsx` | 一张预订卡片（`BookingCard`）；按日期分组时酒店的退房 / 续住那一行（`StayRow`） |
| `view.js` | 页面自己的纯逻辑（单元测试 `test/unit/page-bookings.test.js`）：分组方式、筛选键、加载状态、段标题 / 卡片 / 酒店那一行拍平、格子小字（多个时用短名）、数量 |
| `bookings.css` | 页面样式（`.bkp-*`）和卡片（`.bk-card`）；卡片里的订单号、登机牌、入住退房、价格、芯片、联系人按钮的样式在 `sheets/booking/booking.css` |

## 页面结构

1. **顶部汇总**（出发前 / 进行中，「杂志纸本」：一行字，不是格子）：「2 还没订 · 2 待确认 · 1 到店付（约 HK$…）」
   - 是 0 的那类不写；三类都没有写「都订好了，没有要等的」；还没订是砖红（只标异常）。
   - 每一类点了只看那一类（网址 `?only=idea|pending|property`，再点一下或点筛选芯片的 × 回到全部），正在看的那类海色 + 下划线；
     「中间的 ·」挂在前一项末尾，折行时不跑到下一行开头。
   - 有要盯的免费取消截止时下面再一行「免费取消还剩 1 天 3 小时 · 预订名 ›」（快到期赭石、不到一天砖红），点了打开那个预订。
2. **今天**（行程进行中、按类型分组时）：今天开始的、今晚住的酒店（入住日 ≤ 今天 ≤ 退房日），一行一个（「今晚住这里」「今天 12:00 前退房」「08:30–12:30」；标题按「 · 」分段换行），点了打开详情。
   按日期分组时不放这一张：今天那一组本身就有今天开始的预订和酒店的退房 / 续住那一行。
   今天的「还没订」「待确认」也放进来，后面跟一个小标签（今天要去的话得先订 / 等确认）；还没订的酒店不放（不会「今晚住这里」）。
3. **工具行**：左边「13 个预订 · 1 个已取消」（筛选时换成「只看待确认 ×」芯片），右边分段控件「按类型 · 按日期」（网址 `?by=`，本机记住 `rs7885:bookings-by:<行程>`；都没有时进行中默认按日期、其他按类型）。
4. **分组的卡片**：
   - 按类型：航班 / 酒店 / 活动体验（含门票）/ 接送（含租车，组名自动「接送和租车」）/ 餐厅 / 其他（保险等），组内按时间。
   - 按日期：按各自时区的当地开始日期，组名「1月11日 周一」+「今天 · D2」；今天那组强调色、过去的日子标题变淡、时间未定的在最后。
     **酒店在入住日以外的日子也露面**（`model.js` 的 `hotelStayDays`，`BookingCard.jsx` 的 `StayRow`）：退房那天一行「退房 12:00 前」（过了点写「已退房」、变淡），
     中间几天一行「续住 第 2 晚（共 3 晚）」；按时间和卡片排在一起（退房按退房时间插进去，同一时刻退房在前；续住放在这一天最后），点了打开那家酒店的详情。
     行程中打开「按日期」看今天：要退哪家、今晚住哪、今天订了什么，一组看完，不用往上翻到入住那天。还没订的酒店不算。
   - 段标题和卡片放在同一层（`view.js` 的 `flatList`）：**筛选**时卡片 FLIP 到新位置（`ui/FlipGroup`，消失的淡出）；**换分组方式**时整张列表换掉、新的淡入上浮（卡片跨组飞来飞去、半透明地叠在一起很乱，所以不 FLIP）。
5. **已取消**：最下面一张原地展开的卡（`ui/ExpandableCard`），里面是一行一个（价格划掉、写已退款 / 没退款），点了打开详情。

## 卡片（`BookingCard.jsx`）

- 头：种类图标块、标题（宋体；按「 · 」分段（`parts.jsx` 的 `TitleSegs`），两行时在间隔号后面换行——「Coral Bay Resort · / 豪华大床房带阳台」，不会从店名中间断开）、
  平台 · 时间（时间那一段不拆开：放不下整段换到下一行，不会把「周五」「13:15」单独甩下去；航班只写日期，酒店写几晚，其他写时间段：今天 / 明天用叫法、跨午夜「次日」、跨好几天写区间、时区和行程不同标「香港时间」）、右边凸起的白圆箭头。
- 航班：登机牌（三字码 Instrument Serif 大字、起降时间各自时区、落地跨日 `+1`、日期（不带年份：窄栏里带年份会把「周六」挤断，年份在副标题里）、时长、航班号、时区 · 航站楼、落地时差一句）+ 票根（座位、托运、手提），中间虚线。
- 酒店：入住 / 退房两格（时间大字、日期；今天 / 明天的标在「入住」旁边）、中间几晚、房型一行、地址一行（越南语地址最多两行）、动作行（导航 / 叫 Grab / 给司机看 / 复制地址，`kit/PlaceActions` 完整版；已经退房的不放）。
- 活动、门票、餐厅：一行概要（集合时间、集合点、人数；图标按内容换：钟 / 旗 / 人）、地点名、**带文字的完整动作行**（和酒店同一个样子：街头单手、强光下光看图标猜不出哪个是「给司机看」；地点有下车提示时下面一行小字）。时间已经过去的不放。
- 接送：路线 + 车型。
- **一键联系**（除航班外）：接送是司机（`details.driver_contact_id`），其他是挂在这个预订 / 地点上、能打电话或发 WhatsApp / Zalo 的第一个联系人——「名字 + 打电话（圆）+ WhatsApp / Zalo（写字）」；时间已经过去的（包括还没订的）、已取消的不放。
- **确认单、管理链接**：一排小胶囊。管理链接直接新标签页打开（`openExternal`）；确认单打开详情并滚到「附件」（要先去私有桶取签名链接，iOS 只认点击当下打开的新页面）。
- 每张都有：状态芯片（状态、付款、进行中 / 入住中 / 飞行中、已结束 / 还没订却时间已过的「时间已过」（整趟结束后都不标）、免费取消倒计时）、订单号（等宽，点文字或复制按钮都复制并提示「已复制订单号」、轻震；按住 0.45 秒以上 = 长按，只整串选中、不复制；
  卡片上一行放不下就省略号，复制的照样是整串，整串在详情里大号显示）、价格（`kit/MoneyText`，外币下面一行「约 HK$…」；订金写「已付订金 HK$200」、还没订写「预计」；和付款芯片重复的「到店付」「还没付」不写）。
- 还没订的卡片是虚线边；正在看详情的那张描一圈强调色（`data-current`）。
- **整张卡能点**（打开详情）：卡片上铺一个透明按钮（读屏「查看「…」的详情」，`data-overlay-trigger="booking"`，关掉后焦点回到它），里面能点的东西（复制、动作行、打电话）浮在它上面各管各的——不是按钮里套按钮；按下整张卡缩到 0.98。

## 用到的数据

`useTrip(tripId)` → `store.view.bookings`（已排好序）、`store.view.phase`（阶段和行程时区的今天）、`store.tables.places`（地点：动作行、地址、概要里的地名）、
`store.tables.contacts`（司机）；纯逻辑全在 `sheets/booking/model.js`（`groupBookings`、`filterBookings`、`summarizeBookings`、`todaysBookings`、`cardSubtitle`、`briefLine`、`actionsSize`……）。
金额一律 `lib/money.js` / `kit/MoneyText`；时间一律 `lib/datetime.js`，按预订自己的 `start_tz` / `end_tz`（没写用行程时区）。

## 网址

| 写法 | 意思 |
|---|---|
| `?by=kind` / `?by=date` | 分组方式（替换历史，不压） |
| `?only=idea` / `pending` / `property` | 只看还没订 / 待确认 / 到店付 |
| `?sheet=booking:<预订 id>` | 打开详情（搜索结果、刷新、分享都用这个）；页面进来时把那张卡滚进屏幕、描边 |

进来自动滚（只一次，用户已经滚过就不动）：网址带着详情 → 那张卡滚到中间；行程进行中按日期 → 今天那组的段标题停在顶栏下面。

## 状态

加载中（一行字 + 两张卡的骨架，`ui/Reveal` 交叉淡入）、出错（`kit/ErrorState`，中文原因 + 重试；有缓存时先显示缓存）、找不到行程、没有预订（`PageEmptyState preset="bookings"`）、
筛选后是空的（「没有待确认的预订了」+「看全部预订」）、离线（缓存照常显示，改动进写队列，外壳的同步条负责提示）、只读成员（卡片本来就只读；详情里改动入口隐藏并说明）、深色、375 / 390 / 1280。

## 10-14 评审修改

- 付款状态是「免费」时，卡片底部不再写第二个「免费」（付款芯片已经写了）；免费又没有订单号时不画空的底栏。
- 免费取消截止正好零点时写成前一天「24:00（周五深夜）」（`kit/status.js` 的 `deadlineWhen`）。
- 今天那组的段标题用正文色，「今天 · D2」是海色小字（不是实心横条）。
- 卡片里动作按钮的圆角按同心算（`--radius-sm`）。
