# pages/contacts/ —— 联系人（路由 `contacts`，`#/t/:tripId/contacts`，SPEC §5.11）

大标题「联系人」、返回、右上全局搜索、底栏由外壳画（`section` 页）；这一页只放内容。
搜索框、筛选芯片、「相关」小胶囊、小标、闪一下、外链和贴士页共用（`../tips/common.jsx`、`../tips/common.css`）。

## 页面结构

1. **搜索框**（超过 4 个联系人才出，`?q=`）：名字、身份、备注、类别名、邮箱 / 微信 / LINE、关联的预订和地点名；越南语不带声调；**号码只按数字**（打「0011」找得到 +00 000 0000 0011；至少 3 位）。
2. **类别芯片**（`?cat=`，一行横滑，宽屏折行）：全部 / **今天**（行程进行中且有：关联的预订今天在入住—退房期间、或者关联的地点在今天的安排里）/ 紧急 / 酒店 / 交通 / 餐厅 / 活动 / 向导 / 航空公司 / 预订平台 / 其他（只出数据里有的，数量跟着搜索走）。
3. **概况**：「27 个 · 紧急 6 个」/「酒店 6 个 · 共 27 个」/「今天用得上 7 个 · 共 27 个」/「找到 3 个」。
4. **按类别分组，紧急在最上面**（段标题下一句「报警、急救、医院、领事：点右边的圆钮直接拨号」）。每个联系人一张卡（`ExpandableCard`，页面一个 `useAccordion`，一次只开一张、标题行不跑）：
   - **收起**：类别图标块（紧急是危险色浅底）、名字（+「今天」小标）、身份 · 关联（预订名，没有就地点名；和名字一样的不重复）、
     **号码**（等宽 `--font-mono`、正文色、比副标题大一号；紧急的再大一号、加粗——113 / 115 一眼看到）、备注一行；
     **右上 1–2 个快捷圆钮**（44px）：打电话（强调色实心；紧急类是危险色实心）+ 第一个聊天方式（WhatsApp 绿 / Zalo 蓝，凸起的白圆）；没电话就是聊天方式；只有邮箱给「邮件」。
     圆钮是标题行的“兄弟”（不能把链接放进标题行那个按钮），绝对定位在右上角；标题文字最前面放一块同样大的浮动空位，名字、身份两行绕开圆钮，下面的号码、备注用满整行。
     按下标题行时整张卡（连同圆钮）一起缩 0.98。
   - **展开**：每个号码一行（标签「电话 · WhatsApp」——同一个号码合并；`kit/CopyText` 等宽大字，点了复制、提示「已复制号码」）、
     **带字的大按钮**（58px，图标在上字在下，等宽几列：打电话 / WhatsApp / Zalo / 邮件；紧急的打电话是危险色）、
     邮箱 / 微信 / LINE（点了复制）、备注全文（里面写的别的号码——「总机 +84 …」「另一个电话 1900 …」——做成能点的 `tel:` 链接）、关联的预订（开 `booking` 弹层）和地点（开 `place` 弹层，那里有导航 / 叫 Grab / 给司机看）。
   - **越南手机号推 Zalo**：没写 `zalo`、但电话是越南手机号（+84 3/5/7/8/9 开头）时，展开后也给「Zalo」（`https://zalo.me/0…`）并说明「越南的手机号一般都开着 Zalo」；不放进快捷圆钮（不一定开着）。座机、1900 热线、短号不推。

## 添加 / 编辑（`ContactSheet.jsx`，SPEC 没要求、现场用得上：记下司机、新认识的店家的号码）

- 入口（只有能编辑的成员有）：列表最后「添加联系人」（正在看某一类时预选那一类）、空行程的「添加联系人」、展开后左下「编辑」。
- 面板：名字（新建时自动聚焦、iOS 先叫出键盘）+ 身份 → 类别芯片 → 联系方式（电话 / WhatsApp / Zalo / 邮箱 / 微信 / LINE 一栏一行，号码等宽；
  WhatsApp、Zalo 空着时有「同电话」一键填）→ 备注 → 编辑时「删除这个联系人」。
- 提交（`SubmitButton` 受控）：先检查——名字必填、号码至少 3 位、WhatsApp / Zalo 至少 7 位、邮箱格式；不通过那一栏摇一下（`ui/shake.js` 的参数）、红框、下面说原因、按钮不转圈。
  通过：`store.insert` / `store.update`（编辑只交改了的列）→ `await r.saved`（写进本机队列就算成功，离线也行）→ 对勾 → 面板收回（force）→
  新建的那一个在列表里展开、滚过去、闪一下（`?contact=<新 id>`，同时清掉把它藏起来的筛选）。
- 删除：`store.remove('contacts', id, { undoMs: 6000 })`，外壳弹「已删除 · 撤销」；这里不再确认。改了一半关面板：「放弃未保存的内容？」（`confirmClose`）。
- 只读成员：入口换成一句说明「你是只读成员：可以打电话、发消息、复制，不能添加或修改联系人。」；直接打开网址也是禁用的表单 + 说明、没有提交和删除。

## 链接（和预订详情 `sheets/booking/model.js` 同一套规则）

| 动作 | 链接 |
|---|---|
| 打电话 | `tel:+<数字>`（只留数字和开头的 +；不带 + 的 00 国际冠码换成 +；3 位的急救号也能打） |
| WhatsApp | `https://wa.me/<国际格式的数字>` |
| Zalo | `https://zalo.me/<号码>`（越南号码 +84 换成本地写法 0…） |
| 邮件 | `mailto:<地址>` |

都是真的 `<a href>`（长按能看到、能复制链接），点击走 `lib/native.js` 的 `openExternal`（同一个窗口：iOS 才会唤起电话、WhatsApp、Zalo；以后 iOS 外壳接管），配 `haptic('light')`。

## 网址

| 参数 | 意思 |
|---|---|
| `?q=` | 本页搜索 |
| `?cat=` | `today` 或一个类别 |
| `?contact=<id>` | 全局搜索的结果（和刚添加的那一个）：展开、滚到屏幕中间、闪三下；被筛选藏起来时先清掉筛选 |
| `?sheet=contact-edit:<new \| new-类别 \| id>` | 添加 / 编辑面板 |

## 数据

`useTrip(tripId)`：`view.contacts`（按 `sort`）、`tables.bookings` / `tables.places`（关联、今天）、`view.itemsByDay` + `view.today` + `view.phase`（今天）、`trip.timezone`。
预订的「今天」按各自的 `start_tz` / `end_tz` 换成当地日期（`bookingSpan`）。表结构见 `docs/数据结构.md` B4.8。
写：只有添加 / 编辑面板写 `contacts` 表（`view.canEdit` 为真才有入口）。**只读成员也能用全部动作**（打电话、发消息、复制都不改数据）。

## 状态

加载中骨架、出错 + 重试、找不到行程、空行程、搜不到 /「今天没有要联系的」、离线（有缓存照常看；打电话不要网）、深色、375 / 390 / 1280、超长名字（折行、绕开圆钮）、
没有任何联系方式的联系人（只有备注和关联，没有圆钮）、只有 WhatsApp / 只有邮箱。
