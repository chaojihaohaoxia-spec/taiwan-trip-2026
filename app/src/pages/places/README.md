路由 `places`（`#/t/:tripId/places`），住在「更多」菜单里（外壳的 section 页：左上返回、大标题「地点与评级」、副标题 = 行程名、右上全站搜索都由外壳画）。
这里从大标题下面开始。地点详情、写评级是全站共用的弹层，在 `sheets/place/`、`sheets/review/`（各有 README）。

## 页面结构（从上到下）

1. **搜索框**（本页筛选，不是全站搜索）：名字、当地语名、英文名、别名、地址、标签、介绍；越南语不带声调也能搜（`pho` → Phở），几个词用空格分开、每个都要命中；
   卡片上的名字、当地语名里命中的字高亮。打字先在本地筛，停 400ms 再写进网址 `?q=`（刷新、返回都还原）；Esc / × 清除。
2. **看法**（`SegmentedControl`，`?by=`）+ **列表 ↔ 网格**（`ViewToggle`，`?view=`）：
   - 按类型（默认）：吃喝在前、交通站点和其他在后（`PLACE_KIND_ORDER`），组里按第一次出现在行程里的先后，没进行程的按名字排在后面。
   - 按天：每天一组，组标题「D2 · 1月11日 周一」+ 今天的「今天」标签，下面一行是那天的标题；卡片上多一行「那天用到它的条目：备选 · 时间 · 条目名」。
     一个地点可以在好几天里出现。各天后面是**备选池**（展开），最后是「没排进哪天」的地点。行程进行中点「按天」会把今天那组滚到顶栏下面。
   - 想去：`places.wishlist` 为真的地点（地点详情里点「想去」收进来）。
   - 评级：五档从高到低（夯 / 顶级 / 人上人 / NPC / 拉完了，组标题是档位色块），组里平均分高、评的人多的在前；再「只写了评语」「还没评」（机场车站排最后）。
     行程结束后没记过看法时默认就是「评级」（回顾评得最高的）。
   - 看法、列表 / 网格在这台设备上按行程记住（`localStorage` 键 `rs7885:places:<行程 id>`，读写失败照常用默认值）；网址里有就以网址为准。
3. **种类芯片**（`Chip`，`?kind=`）：全部 + 有地点的种类，数量跟着搜索走；手机上一行横向滑动（两头渐隐），宽屏折行。
4. **一句话概况**：「38 个地点 · 评过 7 个 · 想去 3 个」；筛选时「显示 6 个（共 38 个地点）」。
5. **去过，还没评级**（只在按类型 / 按评级、出发以后、没在搜索时出现）：条目标了完成、我还没评的地点（机场车站不算），最近去的在前；先列 3 个，其余「再看 N 个」。
   点一行直接打开写评级，并关联那一次的条目（`openReviewSheet({ placeId, itemId })`）。
6. **备选池**（按类型时折成一行放在上面——开始搜索、而且备选池里有命中的条目时自动展开，清掉搜索收回去；按天时展开放在各天后面）：没排进哪天的条目（`store.view.pool`），每条：种类、标题（高亮）、地点（点了开地点详情）、
   「排进 D1 D2 …」一排按钮——点一下 `items.day_id` 改成那天、排在那天最后（`store.nextSort`），提示里能撤销；行程进行中不列已经过去的天，今天写「今天」。
7. **地点卡片**（`ViewSwitch` 列表 ↔ 网格，FLIP 拆成底板 / 缩略图 / 文字三块各自动）：缩略图（第一张评级照片，左下角叠种类小图标；没照片是种类图形的浅底）、想去的心形、
   中文名（宋体，两行省略）、当地语名（和中文名一样时不重复）、按天时那一次的时间和条目、「在哪天」小标签（D1 / D2 备选 / 今天 / 备选池）、两个人的评级胶囊（成员首字 + 五档颜色 `--color-rating-*`）。
   点卡片：地点详情从屏幕底部升起（`openPlaceSheet(id, { trigger })`；trigger 用来关掉后把焦点还给这张卡。全站的底部面板都从底部升起，从按钮长出来的只有 ＋、切换面板、更多、给司机看、大图）。网格手机两列、≥1024 三列。

## 用到的数据

- 读：`useTrip(tripId)` → `store.view.places / days / reviewsByPlace / members / pool / canEdit / phase / today`、`store.tables.items`、`data.userId`。
- 写：`store.update('items', id, { day_id, sort_key })`（排进某天）、撤销时改回去；新建条目走 `sheets/item`（空行程的「加行程条目」）。
- 弹层帮手：`openPlaceSheet`、`openReviewSheet`、`openItemSheet`（`sheets/index.js`）。

## 状态

加载中（和真实版式一样的骨架，`Reveal` 交叉淡入）、出错（`kit/ErrorState`：中文原因 + 重试，没网换插图）、找不到行程、空行程（`PageEmptyState preset="places"` + 「加行程条目」，不显示搜索和筛选）、
筛选后没有结果（「没有找到「…」」+ 清除筛选）、想去清单是空的、只读成员（排进某天禁用并说明「只读成员不能改行程安排」）、离线照常（改动进写队列）、深色、375 / 390 / 1280、
超长名字（两行省略）和超长越南语名（一行省略）、0 / 1 / 很多个地点。
