# pages/lists/ —— 清单（`#/t/:tripId/lists`，SPEC §5.7）

「更多」菜单里的「清单」。外壳画大标题「清单」、左上返回、副标题（行程名）、右上搜索、底栏；这一页从大标题下面开始。
点一行打开全站共用的**待办弹层**（`sheets/todo/`，＋ 面板「加待办」、预订详情「加一条待确认」、概览页「加一项」打开的也是它）。

## 页面结构

1. **标签栏**（`ui/Tabs`，指示条弹簧跟随）：待确认 / 待办 / 打包 / 要买，每个带进度小胶囊「3/7」（一条都没有不显示）。
   - 当前标签记在网址 `?list=`（换标签 `setQuery` 替换历史、不压）；没写 → 这次会话上次看的（`sessionStorage`）→ 按阶段挑一个还有没勾的
     （出发前：待确认 → 待办 → 打包 → 要买；进行中：待办 → 要买 → …；结束后：要买 → 待办 → …），都勾完了挑第一个有内容的，空行程是待办。
   - 换标签：内容从换过去的那一侧滑进来（`animateSpring`，x 28px → 0 + 淡入），换之前刚勾的马上沉好。
   - 往下滚：标签栏贴在顶栏下面，换成玻璃胶囊（`IntersectionObserver` 看一个 1px 的哨兵，不监听滚动；同屏只多这一块真玻璃）；同步状态条出现时往下让开它的高度（外壳的 `syncSpace`）。
2. **只读成员**：标签下面一条说明；勾选框、步进器禁用，没有快速添加、左滑、「用常用清单开始」；点行照样能打开看（弹层只读）。
3. **待确认 / 待办 / 要买**（`ListPanel`）：一张卡片——
   - 卡片头：「还有 **6** 项要确认」（Instrument Serif 斜体大数字）+ 进度圆环「2/8」；下面一行快到期提醒（「1 项已过期 · 2 项 24 小时内到期」红色，只有 3 天内的警示色）；
     截止时间按“那一刻人在哪个时区”写（`store.presenceZone(due)`：出发前、回程落地后是香港），和行程时区不同（或和人此刻所在的时区不同）时，
     行里跟一个小标签「香港时间」（和时间轴的「香港」同一种样子）；卡片头不再说「截止时间按越南时间」（行自己说清楚了）。
   - 没勾的：**快到期的排最前面**——已过期 → 24 小时内 → 3 天内（同一档按截止先后），其余（更晚的、没截止时间的）保持清单本来的顺序（`sort` → `created_at`）；
     行程结束以后不催，按清单顺序（`splitRows({ at })`，10-14 现场走查：3 小时后就截止的那项原来排第 7）→ 快速添加 →「已确认 2 · 收起」（整行按钮，每个清单分开记在本机）→ 勾完的（刚勾的在最上面）。
   - 全部勾完：卡片头换成**小小的庆祝**——绿色圆环画满、对勾描出来、六粒小光点散开就没了，「都确认好了 · 8 项都确认过了，安心出发。」+ 触感；只在刚勾完最后一项时播，打开时本来就勾完是静止的样子；减弱动态效果只淡入。不放彩带。
4. **打包**（`PackingPanel`）：
   - 顶部卡片：「还有 **23** 件没装」（跟着筛选）+ 圆环；「隐藏已装好」芯片（本机记住）；「谁的东西」分段：全部 / 共用 / Jeremy / Cathy（owner 在前；网址 `?who=<user id>|shared`，不认识的人退回全部）。
   - 每个分类一张卡：证件 / 衣物 / 电子 / 洗护 / 药品 / 其他（**按整张清单里第一次出现的顺序**，筛选不改变组的先后；不认识的分类照样成组；筛完没有的组不显示）：
     分类图标块 + 宋体分类名 +「1/4」+ 细进度条（装齐了变绿、「✓ 齐了」）；组里没装的在前、装好的沉到下面。
   - 有数量的行用步进器（`ui/Stepper`：「− 2 本 +」，数字 Instrument Serif；量词按名字猜：袜子「双」、护照「本」、充电线「根」……，`extra.unit` 优先，拿不准不写；减到 0 收成「＋ 加入」）。
   - 最后快速添加：上面一行「放进 [自动分类 ⌄]」（选「自动」就按名字猜：「充电宝」→ 电子、「防晒衣」→ 衣物、「防晒霜」→ 洗护，猜不出「其他」）+「记为 Cathy 的」（筛选了谁就记成谁的）；
     加完下面说一句「「卷发棒充电器」加到了**电子**（按名字猜的）」+「改」（打开待办弹层）。
   - 空清单：说明 +「用常用清单开始」（一键加 13 样常见的：护照、信用卡、充电宝……都是共用，数量按两个人算），用不上的左滑删掉。
5. **一行**（`TodoRow`，样稿概览页「出发前待办」那种行）：
   ```
   ◯  标题（15px 半粗，最多不限行，只在标点处折行）          [− 2 件 +]
      ⏱ 还剩 5 小时 · 今天 23:59 前   ● Cathy
      备注（没勾的显示全文；勾完的一行）
      [📞 +84 …]  [🛏 椰影湾酒店]  [📅 D2 · 今天]  [🚩 D2 出海浮潜]
      ✓ Cathy 勾的 · 昨天 21:10                （勾完的）
   ```
   - 整行铺一个透明按钮（点了打开待办弹层编辑，按下整行换底色），勾选框（44×44 热区）、步进器、小链接浮在它上面各管各的，可点的东西不互相嵌套。
   - 截止时间：过期 / 不到 1 天红色、1–3 天警示色（和免费取消倒计时一个口径，`kit/status.js` 的 `formatLeft`）、更晚普通色；分段显示，只在「 · 」处折行；勾完的不再提醒。
   - 负责人 `kit/PersonChip`（是我的后面加「我」；打包筛选了某个人时不重复显示）。
   - 备注：没勾的显示全文（备注里写的多是「找谁、说什么、几点前」，在街上要一眼看全、不用再点开）；勾完的只留一行。
   - 备注里认出来的**电话**（`+84 …` 国际写法，或 0 开头 9–11 位的本地号码）、**邮箱**、**网址**（`https://…` 或 `.com / .vn / .hk …` 结尾的裸域名）
     在小链接那一排的最前面各给一个**强调色浅底的动作胶囊**（`model.js` 的 `noteParts` / `noteActions`，同一个只给一次、最多 3 个；钟点「08:15–12:45」、
     日期「01-09」、金额、订单号不会被当成电话）：「📞 +84 123 …」点了直接拨号、「↗ example.vn/hours」开新标签页、「💬 邮箱」写邮件；
     标题或备注里提到 WhatsApp 的国际号码改成「WhatsApp +84 …」（`https://wa.me/<号码>`，通用链接唤起 App）。都走 `lib/native.js` 的 `openExternal`；
     长按照样出 iOS 的「拨打 / 拷贝」菜单。勾完的行不再给这些胶囊。
     不在备注文字里做下划线链接：行内链接的可点区域扩到 44 高会盖住上下几行字，点备注想编辑却打了电话。
   - 小链接（凸起的白胶囊）：预订 → 打开预订详情弹层；条目 → 那天并展开那一条（`#/t/…/day/<date>?item=<id>`，备选池里的 → 概览 `?item=`）；只关联了哪天 → 那天（日期是昨天 / 今天 / 明天就直接这么说）。删掉的条目、找不到的预订不显示。
6. **勾选**：圆圈从中心弹出 + 白勾描出来（`ui/Checkbox`）、标题一条线从左往右划过去（多行标题每行都划）、触感（`haptic('success')`，取消 `light`）；
   数据**马上**写（乐观更新，离线也行），但行**先留在手指下面**：最后一次勾选 0.9 秒后，所有刚勾的一起 FLIP 沉到「已完成」最上面（取消勾的一起浮上来；移动时那一行浮起来压在别的行上面经过），
   然后提示「已装好「护照」· 撤销」/「已买到 3 样 · 撤销」——连着勾好几项不会一勾就跳走、点错下一行。撤销 = 把这一批取消勾选（又 FLIP 回原位）。
   - 留在原位期间**行的版式也按勾之前算**（`TodoRow` 的 `held` / `heldFrom`）：勾上那一下不多出「我勾的 · 刚刚」、备注不收成一行，行高不变，下一行不会被挤下去；
     版式的变化跟着沉底的那次 FLIP 一起发生（交互评审 P1-3）。勾选框和划线照常马上变。
   - 到点时手指还按在列表上（`useSinkHold` 的 `pressStart` / `pressEnd`）：先不沉，松手 300ms 后再沉——沉的那一刻手指下面换了一行，这一下不会丢。
   - 键盘：空格勾选以后焦点在那一行的勾选框上，沉下去以后焦点跟着那一行（不掉到 body）。
7. **快速添加**（`kit/InlineAdd`）：回车 / 点「添加」提交，输入框清空、焦点留着、键盘不收，接着打下一条；一次粘贴好几行就加好几条；新的一项从输入框上面弹出来（FLIP）；
   自动带上当前清单、打包的分类和筛选的人；排到这个清单最后（`sort` 比现有都大）。出错（中文原因）时字留着、输入框摇一下。
8. **左滑删除**（`kit/SwipeRow`）：往左拉露出「删除」，拉过整行一半直接删（iOS 邮件那种），外壳弹「已删除「…」· 撤销」（数据层的撤销窗口）。

## 用到的数据

`useTrip(tripId)` → `store.view.todosByList`（四个清单，已按 `sort` → `created_at` 排好）、`store.view.members` / `membersByUser`（谁的东西、负责人）、
`store.view.canEdit`（只读成员）、`store.view.phase`（默认标签）、`store.tables.bookings` / `items` / `days`（小链接）、`store.dayNumber(date)`、`store.memberName(userId)`。
写：`store.toggleTodo(id, done)`、`store.setTodoQty(id, qty)`、`store.insert('todos', …)`、`store.remove('todos', id)`（撤销由外壳弹）。
时间一律按行程时区（`trips.timezone`，`lib/datetime.js`）；「现在」用 `kit/useNow`（`?now=` 拨过的也照常走）。

## 网址

| 写法 | 意思 |
|---|---|
| `?list=confirm\|todo\|packing\|buy` | 当前标签（替换历史） |
| `?who=<user id>\|shared` | 打包：谁的东西（替换历史；全部 = 不写） |
| `?todo=<id>` | 搜索结果跳过来：切到那个清单，必要时放开筛选和「隐藏已装好」，滚到中间、闪两下底色；用完从网址去掉 |
| `?sheet=todo:<id>` / `?sheet=todo:l.packing` | 待办弹层（见 `sheets/todo/README.md`） |

本机记住（丢了也没关系）：这次会话上次看的标签（`rs7885:lists:tab:<行程>`，sessionStorage）、每个清单收没收「已完成」（`rs7885:lists:hide-done`）。

## 状态

- 加载中：标签 + 一张清单卡的骨架（`ui/Skeleton`），数据到了 `Reveal` 交叉淡入；有缓存时直接显示缓存。
- 出错：`kit/ErrorState`（中文原因 + 重试；断网换「现在没有网络」的插图）。找不到行程：说明 +「回到行程列表」。
- 空：每个清单各自的说明（`PageEmptyState preset="lists" compact`）+ 快速添加；打包另有「用常用清单开始」。筛选某个人后没有东西：「Cathy 没有要带的东西」+「看全部」。
- 离线：照常勾、改、加、删（进写队列），外壳的同步状态条负责提示；贴顶的标签栏让开同步条。
- 行程结束以后：不催——没勾的截止时间平平地写「1月8日 23:59 前」（不标红、不写「已过期」），卡片头不提醒、不说时区。
- 只读成员、深色、375 / 390 / 1280（桌面内容最大宽度 `--content-max`）、超长标题和备注（折行，不压到步进器）、0 / 1 / 很多条：都有 e2e。

## 需要整合进共用层的（页面里先做了局部版本）

- （已整合）药品图形 `pill` 在 `kit/glyphs.js`，`PackingPanel` 直接用 kit 的 `Glyph`。
- `model.js` 的 `noteParts` / `noteActions` 和 `ActionChip.jsx`（备注里认出电话 / 邮箱 / 网址，给「打电话 / 打开网页」胶囊）对别的页面也有用（预订的备注、条目的说明、联系人的备注）：
  建议整合时把 `noteParts` 挪到 `lib/linkify.js`、`ActionChip` 挪进 `kit/`（类名 `k-act`），清单页和待办弹层改成从那里引。现在别的页面要用可以先直接引 `pages/lists/ActionChip.jsx`（样式自带）。
- 待办弹层的日期 / 钟点输入框藏掉了浏览器自带的小日历、小钟图标、点哪里都 `showPicker()`（`sheets/todo/todo.css` + `TodoSheet.jsx` 的 `openPicker`）：英文系统 375 宽「11:59 PM」不再被切。
  记一笔、加条目的日期时间框如果也有这个问题，可以把这两处做成 `ui/` 的一个小工具（例如 `ui/DateTimeInput`）统一用。
