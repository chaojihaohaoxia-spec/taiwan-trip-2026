# sw/ —— Service Worker 模板

`sw.js` 不是直接发布的文件：`npm run build` 把里面两行占位换成真实值，写到仓库根目录的 `sw.js`：

```js
const VERSION = '__SW_VERSION__';   // → "2.0.0+<内容哈希前 10 位>"，和 index.html 的 <meta name="app-version"> 相同
const PRECACHE = __SW_PRECACHE__;   // → ["./", "manifest.webmanifest", "icons/…", "assets/…"]（相对 SW 所在目录）
```

两行都必须原样保留（构建会检查各有且只有一行）。

## 策略

| 请求 | 处理 |
|---|---|
| 页面导航到应用入口（`./`、`./index.html`，带不带 `?demo` 都算） | **缓存优先**：用这一版 SW 自己预缓存的入口页——页面版本永远和控制它的 SW 一致（按需加载的分包一定在同一版缓存里，发版后断网也能打开没去过的页面）；秒开，不等网络（酒店 Wi-Fi 认证页、漫游弱信号也不会卡在启动画面）。缓存里没有入口页时才走网络（`cache: 'no-cache'`），最多等 4 秒，超时 / 失败用任一版本缓存的入口页 |
| 网页字体（同源 `.woff2`：`assets/<名>-<内容哈希>.woff2`，也认 `fonts/` 下的） | **不在安装时预缓存**；第一次用到时缓存优先，存进单独的、不带版本号的 `rs7885-fonts` 缓存（见下） |
| 预缓存清单里的同源资源（带哈希的 js/css/图片、图标、manifest） | **缓存优先** |
| 同源 `assets/` 下、不在本版清单里的资源 | 先查所有本应用缓存（新版 SW 已装好时它的缓存），都没有再走网络 |
| 跨域请求（Supabase、天气、汇率、地图瓦片…） | **不拦截、不缓存** |
| 同源其他页面（`guides/`、`legacy/`、`app/` 源码…） | 不拦截 |

- 版本号是内容哈希：内容不变就不会提示更新。只来自 `src/dev/`、`demo/` 的分包和演示照片不进预缓存。
- 安装时 `cache: 'reload'` 拉取，保证拿到的是这一版的文件。
- 新版装好进入 waiting → 页面显示「有新版本，点此刷新」→ 点了发 `SKIP_WAITING` → 接管 → 页面刷新一次（刷新后由新版缓存打开）。
- 因为页面是缓存优先打开的，发现新版本靠 `lib/pwa.js`：每次启动检查一次，回到前台最多每 15 分钟一次，前台常驻每小时一次（`registration.update()`，`updateViaCache: 'none'` 绕过 HTTP 缓存）。
- 激活时删除自己的旧版本缓存（`rs7885-shell-*`）和旧网站的缓存（`th-*`）。
- **字体缓存** `rs7885-fonts`：思源宋体切成 52 片（见 `static/fonts/README.md`），一屏只用到其中十来片，装 SW 时全下载太浪费，所以构建清单里虽然有 `.woff2`，
  安装时会去掉（`INSTALL_LIST`），浏览器真的要用某一片时再下载并存进字体缓存，之后离线也能用。这个缓存**不带版本号**、发新版不清
  （文件名带内容哈希，名字一样就是同一个文件，换版本不用重新下载）；激活新版时只删掉新版清单里已经没有的旧字体（`pruneFonts()`），不会越积越多。
  `fonts/` 下的文件不在清单里，不会被删。离线时第一次用到、还没缓存过的字体取不到，浏览器按 `font-display: swap` 用系统字体显示，不影响使用。
  第一次打开网站时 SW 还没接管，那一次下载的字体只在浏览器的 HTTP 缓存里；从第二次打开起经过 SW，才存进字体缓存。
- **从旧网站升级**：发现 `th-*` 缓存说明是从旧版来的，旧页面不认识更新提示，于是直接 `skipWaiting`、接管、让打开着的页面刷新一次。注意：激活回调里**不能 await `client.navigate()`**（导航要等激活完成才派发，互相等死），e2e 覆盖了这个场景。
- 消息：`{ type: 'SKIP_WAITING' }`；`{ type: 'GET_VERSION' }`（用 MessageChannel 回复 `{ version }`）。

改了这里要跑 `npm run e2e -- pwa`（安装、离线、更新提示、旧版接管、字体不进安装缓存都有测试）和 `node --test test/unit/sw.fonts.test.js`（字体规则的单元测试）。
