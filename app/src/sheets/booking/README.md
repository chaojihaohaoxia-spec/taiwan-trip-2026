# sheets/booking/ —— 预订详情弹层（`?sheet=booking:<id>`，SPEC §5.6、§9.2）

全站共用、按需加载的底部面板（`Sheet`，档位 `['content', 'large']`）。打开一律用 `sheets/index.js` 的帮手：

```js
import { openBookingSheet } from '../sheets/index.js';
openBookingSheet(booking.id, { trigger: e.currentTarget });   // 从这个按钮打开，关掉后焦点回到它
```

网址写法（`sheets/args.js`）：

| 写法 | 意思 |
|---|---|
| `?sheet=booking:<预订 id>` | 看详情 |
| `?sheet=booking:id.<预订 id>~m.edit` | 直接进「改」模式（只读成员还是看） |
| `?sheet=booking:id.<预订 id>~t.files` | 打开后滚到某一节：`files` 附件 / `contacts` 联系人 / `todos` 待办 / `payment` 付款 / `links` 链接 |

| 文件 | 内容 |
|---|---|
| `BookingSheet.jsx` | 弹层本身（default 导出）：找预订、看 ↔ 改切换（交叉淡入上浮）、底部按钮（「修改状态、付款和订单号」/「取消」+「保存」）、改了一半关面板先问 |
| `Detail.jsx` | 「看」：见下 |
| `EditForm.jsx` | 「改」：状态、付款、订金金额、谁付的、付款方式、订单号、备注 |
| `parts.jsx` | 预订页卡片和弹层共用的部件（别的页面也能用）：`CodeText`、`BookingChips`、`FreeCancelChip`、`BoardingPass`、`PassStub`、`HotelStay`、`PriceTag`、`ContactActions`、`TitleSegs`（标题按「 · 」分段，两行时在间隔号后面换行） |
| `model.js` | 纯逻辑（Node 里能直接测，单元测试 `test/unit/page-bookings.test.js`）：分组（按日期时酒店的退房 / 续住那一行 `hotelStayDays`）、筛选、汇总、免费取消、时间、标题分段、登机牌、入住退房（房型里已经写了的床型、景观不再重复）、价格和付款、详情、关联、联系方式、附件和链接、一键改状态、编辑表单 |
| `booking.css` | 共用部件（`.bk-*`）和弹层（`.bks*`）的样式 |

## 「看」（`Detail.jsx`）从上到下（到了现场最先要的在上面）

1. **时间**：航班是大号登机牌（三字码、起降时间各自时区、跨日 `+1`、时长、航站楼、落地时差）+ 票根（座位、托运、手提）；
   酒店是入住 / 退房两格 + 房型；其他是种类图标 + 时间段（今天 / 明天、次日、时区）+ 概要（集合时间、集合点、人数 / 路线、车型）。
2. **状态芯片** + **一键改状态**（编辑成员）：待确认 →「商家确认了」、还没订 →「已经订好了」、已订没付清 →「已付清」/「到店付好了」/「尾款付清了」
   （没记谁付的就记成点按钮的人，Toast「已付清 · 记成 Jeremy 付的」，不对在「修改」里改）。改完 Toast 带「撤销」（写回原值）。
3. **订单号**：大号等宽；点文字或复制按钮都复制（「已复制订单号」、轻震、图标变对勾，不留选中的蓝底）；按住 0.45 秒以上（长按）只整串选中，交给系统菜单。
   很长的订单号整串显示、折行时每行排满（卡片上的小号一行放不下就省略号）。
   没有订单号时写「还没填订单号，现在填」（直接进改）。
4. **免费取消**：一行带底色的提醒：还早是蓝「1月5日 23:59 前可免费取消 · 越南时间 · 还剩 3 天」、≤48 小时警示色、≤24 小时红、过了灰「已不可免费取消 · 截止时间是 …（越南时间）」；预订开始了就不提醒。
5. **地点**（酒店、活动、门票、餐厅、租车的取车点）：名字 + 当地语名、地址、`kit/PlaceActions`（导航 / 叫 Grab / 给司机看 / 复制地址，下车点规则在 kit 里）。
6. **资料待核**（`extra.待核` / `extra.to_verify`，导入时写的一句「价格、订单号资料里没有」）：警示色一行。
7. **备注**：超过 6 行先收起（最后一行渐隐）+「展开全部」——原地展开，`motion/hooks.js` 的 `useHeightFlip`（下面的内容跟着平滑下移，收起时反过来；箭头 `MorphIcon chevron` 转过去）。
8. **附件**（确认单）：私有桶的路径 → `data` 的 `useSignedUrl`（出场动画播完才去取）；拿到链接前转圈「正在取链接…」，8 秒没拿到写原因（没网 / 没取到）、点一下重试；
   点了走 `lib/native.js` 的 `openExternal(url, { newTab: true })`（以后 App 外壳用系统浏览器打开）；刚上传还没同步的本机文件（`blob:`）交给链接本身。
   **编辑成员能「添加确认单」**（照片 / 截图 / PDF，可以一次选几个；`store.upload('bookings', file)` → 路径写进 `attachments`，离线也行、联网后自动上传）和**移除**（先确认；只是从这个预订里拿掉，Toast 能撤销）。
9. **付款**：总价（还没订时「预计价格」、免费写「免费」）、已付 / 已付订金（谁付的 · 付款方式）、还要付（警示色）、到店付（警示色 + 付款方式）、押金、行李加购（谁付的、哪天）、
   账本里记了几笔（点了去账本 `?expense=`）；已付 / 付了订金、有价格、账本里却还没有这笔时提醒一句「账本里还没记这笔，记一下，回头结算才算得上」；编辑成员有「记一笔」（预填这个预订、地点、日期（在行程里时）、分类：酒店 → 住宿、航班 / 接送 / 租车 → 交通、餐厅 → 餐饮、门票 → 门票、活动 → 活动）。
10. **详情**：按种类列出 `details`（docs B5.7）——航班的航班号 · 航司、舱位、座位、乘客、航站楼、飞行时长、手提 / 托运（加购）、餐食；酒店的房型、床型、房间 · 人数、景观、早餐、几点起入住、几点前退房、特色；
    活动的集合（地点 · 时间）、人数、包含、入场凭证；接送的路线、车型、人数；餐厅的人数、订金；租车的取车、还车、车型；保险的保障、受保人数。另有「附赠和权益」（`extra.perks`）。
11. **链接**（管理订单、官网……）：标签 + 域名，`openExternal(url, { newTab: true })`；只认 http(s)。
12. **联系人**：司机（`details.driver_contact_id`）→ 挂在这个预订上的 → 同一个地点、没挂在别的预订上的；地点自己的电话（联系人里没有同一个号码时）也放进来。
    一行：名字 → 身份 · 电话（没有任何联系方式写「没有留电话」）→ 备注 → **一排按钮放在文字下面、和名字左对齐**：打电话（`tel:`，强调色）、WhatsApp（`https://wa.me/<数字>`）、Zalo（`https://zalo.me/<号码>`，+84 换成 0）、
    邮箱 / 微信 / LINE（`kit/CopyText` 胶囊，一行放不下省略号，读屏是全文，点一下复制）。
13. **待办**（`todos.booking_id`）：没勾的在前，能直接勾（`store.toggleTodo`）；写清单名、截止时间（只有「已过期 · 昨天 22:59 前」那一段红字，备注照常）、备注；长待办的圆圈对齐第一行；编辑成员有「加一条待确认」（`openTodoSheet({ list: 'confirm', bookingId })`）。
14. **行程里的安排**（`items.booking_id`）：D 几 + 标题 + 日期时间，点了去那一天并展开那一条（`#/t/<行程>/day/<日期>?item=<id>`；备选池的去概览 `?item=`）。
15. 只读成员的说明（「改状态和付款请 Jeremy 或 Cathy 来改」，名字从成员表来）、最后修改（谁 · 什么时候）。

## 「改」（`EditForm.jsx`）

状态（分段控件：还没订 / 待确认 / 已订 / 已取消）、付款（芯片：未付款 / 已付 / 付了订金 / 到店付 / 免费 / 已退款）、
付了订金时「已经付了多少」（`lib/money.js` 的 `parseAmount`：`50万`、`500k`、`HK$200` 都认，后面写币种名；下面边打边换算「= 500,000₫（约 HK$152） · 总价 2,400,000₫（约 HK$727）」）、要记谁付的时「谁付的」（成员分段，默认自己）、
付款方式（「不要写卡号或卡号尾数」）、订单号（等宽、不自动纠正）、备注。底部「取消」+「保存」（`ui/SubmitButton`：转圈 → 对勾 → 回到看的样子）。
校验在 `model.js` 的 `patchFromForm`：订金要大于 0、不超过总价、要有价格币种（出错：那一栏摇一下（`ui/shake.js` 的参数）+ 红字 + 保存按钮摇头「重试」）；
只提交真正改了的字段（和开始改时的那一份比，别人同时改了别的字段不会被冲掉）；不是订金就清掉已付金额；不用记谁付的就清掉。
改了一半关面板（拖走、点遮罩、Esc、×、返回手势）先问「放弃未保存的内容？」。离线照常保存（进写队列）；本机存储暂时不可用时提示一句。

## 给别的页面用

- 概览页的去程航班卡、每天页条目里的关联预订可以直接用 `parts.jsx`：`<BoardingPass booking tripTz />`、`<BookingChips booking tripTz />`、`<FreeCancelChip booking tripTz short />`、`<CodeText code />`、`<PriceTag booking brief />`。
- 时间、免费取消、价格的说法用 `model.js`：`whenLine`、`cardSubtitle`、`bookingFreeCancel`（≤48 小时警示，和 `kit/status.js` 的 3 天不一样，见交付报告的整合建议）、`priceView`、`paymentView`。
