# sheets/review/ —— 写评级（弹层 `review`，SPEC §5.9，docs/数据结构.md B4.13 / B5.10）

打开：`openReviewSheet(place.id)` 或 `openReviewSheet({ placeId, itemId })`（从某个条目 / 「去过还没评」打开时关联那一次：`reviews.item_id`、去的时间）。
网址 `?sheet=review:p.<地点 id>~i.<条目 id>`。**每人每个地点一条**：已经评过，打开就是编辑我那条（`store.saveReview`：有就改、没有就建）。只读成员也能写自己的。

| 文件 | 内容 |
|---|---|
| `ReviewSheet.jsx` | 弹层本体：标题（地点名）+ 副标题（「我的评级 / 改我的评级 · 那一次的时间和条目」或当地语名）、表单、底部保存按钮、关闭前确认、删除 |
| `form-model.js` | **纯逻辑**（单元测试 `test/unit/page-places.test.js`）：已有评级 → 表单（`initialForm`）、手机输价格（`wantsThousands` / `priceInputMode` / `timesThousand` / `forgotThousands`：「千」按钮、键盘种类、忘了按「千」的提醒）、价格解析（`parsePrice`：千分位、全角、币种符号、`45k`、`4.5万`、`1tr2`、越南写法 `450.000`；空 = 没填，看不懂 / 0 / 负数给中文原因）、表单项 ↔ `LogEntry`（数量、备注、照片路径原样保留）、改没改过（`formKey`）、空表单、价格有错的项、保存的 patch（`buildPatch`：只放评级几个字段，关联条目和去的时间只在原来没有时写）、价格能选的币种（当地币在前）、去的时间（`visitedAtFor`） |
| `review.css` | 样式（`.rv-*`） |

## 表单（从上到下）

1. **评个级**：五个大色块按钮（`--color-rating-5…1`，没选时白底 + 底下一道档位色，选中实心白字），选中用 `motion` 的弹簧弹一下（bouncy），轻触感 `haptic('selection')`；
   再点一下取消（可以只写评语）；下面一行说明「夯：好到离谱，必须再来（再点一下取消）」。键盘：radiogroup，← → Home End。375 及更窄时字号、字距收一点。
2. **评语**：随内容长高的输入框（最多 2000 字）。
3. **吃了什么 / 买了什么**（吃喝类地点「吃了什么」在前，其他「买了什么」在前）：`kit/InlineAdd` 打名字回车就加一条、可以连着加；每条：名字、价格（输入框 + 币种下拉，
   实时显示 `formatMoney` 的结果「45,000₫（约 HK$14）」，失焦时规范成千分位；看不懂标红、不让存。键盘按币种：越南盾这类没有小数的用纯数字键盘（`inputmode=numeric`），港币等用带小数点的；**手机数字键盘打不出 k**，所以越南盾（以及印尼盾、韩元）输入框里有一个「千」按钮：45 →「千」→ 45,000（按下不抢焦点，键盘不收起），不到 1,000 时下面提醒「45₫ 太少了？点这里改成 45,000₫」——和记一笔面板的「千」同一个叫法；电脑上直接打 45k、4.5万 照样认）、好不好吃 / 值不值（同样五档的小胶囊，再点取消）、删掉（`FlipGroup` 动画）。最多 30 条。
4. **照片**（可不加，最多 12 张）：选了先本机预览（标「新」），保存时用数据层 `store.upload('reviews', file)` 压缩上传到私有桶（离线进写队列，联网后自动传）；去掉的旧照片保存后连文件一起删（`data.files.remove`）。
5. **删除我的评级**（编辑时）：先确认，删除后外壳的「已删除 · 撤销」能撤回。
6. 离线时一行说明「现在没有网络：照常保存，联网后自动同步（照片也会自动上传）」。

底部 `SubmitButton`「保存评级 / 保存修改」：文字 → 转圈 → 对勾；什么都没写时禁用并说明；失败摇头 + 中文原因（价格看不懂时直接说哪一条）。
改过没保存就关（Esc、往下拉、返回、×）先问「放弃未保存的内容？」（`Sheet` 的 `confirmClose`）。

## 和地点详情的衔接

底部面板同一时间只开一个。从地点详情点「给它评个级 / 修改」是把地点详情换成写评级（`replace`），`sheets/place/flow.js` 记着从哪来；写评级关掉（保存、删除、取消、往下拉、返回手势）后把地点详情开回来。
从网址直接打开（刷新、分享链接）、从地点页的「去过还没评」打开时，关掉就回到底下的页面。

## 表单状态

放在“这一次打开”的会话里（signals）：标题、副标题、底部按钮、关闭前确认都在 `Sheet` 外层，和表单内容共用同一份；数据到了以后只初始化一次（对方同时改了我的评级不会冲掉我正在填的）。
