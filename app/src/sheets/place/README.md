# sheets/place/ —— 地点详情（弹层 `place`，SPEC §5.9、§6、§10）

打开：`openPlaceSheet(place.id, { trigger })`（网址 `?sheet=place:<地点 id>`，刷新、返回、分享链接都能恢复）。地点页、地图、每天页、全站搜索都用它。
底部面板两档：半屏先看名字和动作行 → 往上拉到大档看全部。面板外壳（玻璃、把手、标题栏、关闭）由 `overlay/Sheet` 画。

| 文件 | 内容 |
|---|---|
| `PlaceSheet.jsx` | 弹层本体：读取中骨架 / 找不到这个地点；头部、动作行、我们的评级、在行程里、介绍、信息、相关贴士 |
| `parts.jsx` / `parts.css` | 地点页、地点详情、写评级**共用的小部件**：`RatingChip` / `RatingChips`（成员首字 + 五档颜色胶囊，新出现或换档时弹一下）、`DayTags`（「D1」「D2 备选」「今天」「备选池」）、`ScheduleDays`（备选池的条目一键排进某天）、`AddToDay`（没进行程的地点一键加进某天：新建一条条目）、`PlaceThumb`（评级照片或种类图形；`kindBadge` 时照片左下角叠种类小图标）、`HeartGlyph`、`popSpring`、`memberColor` / `memberLabel` / `initialOf` |
| `model.js` | **纯逻辑**（单元测试 `test/unit/page-places.test.js`）：评级五档 `RATING_TIERS`（5 夯 / 4 顶级 / 3 人上人 / 2 NPC / 1 拉完了）、`ratingSummary`（平均四舍五入：夯 + 顶级 = 夯）、`placeVisits`（每个地点被哪些条目用到：排进哪天的 / 备选池里的）、`dayTags`、`reviewsByUser`、`reviewHasContent`、`needsReview` / `latestDoneItem`、`placeTips`、`placeLinks`、`scheduleTargets`（`hidePast`：行程中不列过去的天）、`itemKindForPlace`、`localName` / `englishName`（和中文名一样的不重复显示）、`visitWhen` / `itemTimeText` |
| `flow.js` | 「地点详情 → 写评级 → 回到地点详情」：底部面板同一时间只开一个，点「写评级」是换成写评级面板（`replace`），这里记一笔从哪个地点来的，写评级关掉后再把地点详情开回来 |
| `place.css` | 样式（`.pls-*`） |

## 内容（从上到下）

1. **头部**：中文名是面板标题（宋体）；当地语名大字（系统字体半粗，越南语声调清楚；和中文名一样时不显示）；英文名（和前两个都不一样时才显示）；
   种类芯片、「大概位置」（`coord_precision: 'approximate'`）、「没有坐标」、**想去**（凸起的白胶囊，开着是强调色浅底 + 实心心形；编辑者点一下切换，提示里能撤销）；营业时间。
2. **动作行** `kit/PlaceActions` 完整尺寸：导航 / 叫 Grab / 给司机看 / 复制地址 / 打电话（有电话时）/ 记一笔。下车点（`extra.ride_via`）、下车提示（`ride_note`）、
   开车到不了（`no_road` → 「去缆车站」）都由组件处理，说明行在按钮下面。「记一笔」：今天的行程里有这个地点时预填今天那一条和日期。
3. **我们的评级**：每个写了东西的成员一张（头像色块、名字、档位胶囊或「只写了评语」、评语、吃了什么 / 买了什么（名字 ×数量、档位、价格带折合港币）、照片（点开 `photo` 弹层大图）、去的时间）；
   两人都评了显示「平均 夯」；没评的人写「Cathy 还没评」。我评过：我那张右上「修改」；没评过：「给它评个级」——去过（条目标了完成）或行程已经开始时是主按钮，出发前是浅色次要按钮。
4. **在行程里**：哪几天的哪些条目（「D2 · 13:00–14:00 · 备选 / 雨天方案 / 今天」+ 条目名 + 已完成 / 已跳过），点了去那一天并展开那一条（`#/t/…/day/<日期>?item=<id>`）；
   备选池里的条目：「排进 今天 D3 D4」；完全没进行程：「还没排进哪一天 · 加进 D1 D2 …」（新建条目，标题 = 地点名，种类按地点种类，放在那天最后，可撤销）。
5. **介绍**（Markdown 转纯文字，超过 4 行先收起「展开全部」）。
6. **信息**：地址（点一下复制，长越南语地址整段折行）、电话（点一下复制；打电话在动作行）、下车点（点了换成那个地点的详情）、下车提示、开车到不了、坐标精度；链接（`links` + `maps_url`，只留 http(s)，外链走 `lib/native.js` 的 `openExternal`）。
7. **相关贴士**（`tips.place_id` 是这个地点的；置顶 / 防坑在前）：点了去贴士页那一条（`?tip=`）；有当地语原文的有「给对方看」（`driver` 全屏大字卡）。

## 权限和状态

- 只读成员：想去看起来是禁用的（`aria-disabled`），点一下提示「只读成员不能改想去清单」（手机上没有悬停提示）；排进 / 加进某天、记一笔禁用，下面一行写原因；评级照样能写（每人自己的，RLS 允许）。
- 数据还在读：骨架；地点 id 不对：「找不到这个地点」；离线：照常，改动进写队列。

## 对接

- 地图页的地点面板、每天页条目里的地点名、全站搜索的地点结果都用 `openPlaceSheet(id)`；回顾页「评级最高的地方」可以用 `model.js` 的 `ratingSummary` / `RATING_TIERS` 和 `parts.jsx` 的 `RatingChips`。
