`helpers/`：

- `fake-window.js`：`createFakeWindow(url)` 假浏览器（真实的历史条目栈，`back/forward/go` 异步触发 popstate + hashchange，滚动位置，document.title，点击事件）；`userNavigate(hash)` 模拟手改地址栏；`fakeAnchor(href)`；`memoryStorage()`；`flush()` 等异步队列跑完。
- `tokens.js`：解析 tokens.css，按浅色 / 深色算出每个颜色变量的实际 RGBA（支持 `var()` 后备和“没设的变量往外传无效值”、`color-mix(in srgb …)`、OKLCH 相对颜色 `oklch(from … l c h)`（含 `calc()`、`clamp()`，超出 sRGB 时降彩度）；`@supports` 里那一块 OKLCH 版本用 `readRelativeBlock()` 读出来，盖在旧浏览器版本上算），`contrast()` 算 WCAG 对比度。

约定：被测的模块必须是纯 `.js`（Node 不认 JSX）；测试名用中文写清楚“在什么情况下应该怎样”。
